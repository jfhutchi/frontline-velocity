# Assets

This directory is reserved for original game assets.

## v0.0.1 status

The vertical slice ships with **no binary assets** — all visuals are
primitive Babylon.js meshes (boxes, cylinders, spheres) tinted with
material colors, and all audio is procedurally generated through the
Web Audio API in `src/game/audio/AudioManager.ts`.

## Future asset plan

- `/models/` — `.glb` / `.gltf` files for tanks, jeeps, infantry, props.
- `/textures/` — diffuse/normal/roughness maps for terrain and units.
- `/audio/` — `.ogg` / `.wav` files for engine, cannon, voice, music.
